ORBIT — AI PROMPTS AND RESPONSES



1. GAME CONCEPT
Prompt summary: Make a game inspired by Human Resource Machine.
Response summary: Build an original visual programming puzzle in which the player writes instructions for a robot. In ORBIT, a service drone processes numerical packets in an original space-station setting.


2. VISUAL DESIGN
Prompt summary: Make the game more attractive and lively, with visible robot actions and a better opening screen.
Response summary: Created original geometric artwork, including a planet, observation window, transport platforms, packet crates, server lights, and a hovering drone. Later revisions introduced an illustrated workshop with cream, teal, and coral colors, readable instruction cards, and a separate mission map. No external media assets were used.

3. DRAGGING, JUMP CONNECTIONS, AND OPTIMIZATION
Prompt summary: Add more levels, draggable instructions, draggable arrows for loops, and performance measurements after solving a mission. The original request also asked to reproduce official HRM levels.
Response summary: Created an original 30-mission draft. Added card insertion, reordering, deletion, draggable jump endpoints, and edge scrolling. Each card has a stable integer ID so jumps remain connected when cards move. Deleting a target leaves its jump invalid until reconnected. Verification uses the same interpreter as animated execution and reports code length, average steps, packets per 100 instructions, reference costs, and session bests.

4. FINAL MISSIONS AND ANSWER ARCHIVE
Prompt summary: Make later levels significantly harder, reduce the campaign to about 11 missions, replace the rectangular level layout, and add an answer page with the fastest solutions.
Response summary: Reduced the campaign to 11 original missions arranged as circular stations on a winding orbital route. Topics progress from data movement and arithmetic to multiplication, division, Fibonacci, primality, and sorting. Added an Answer Archive with reference programs, explanations, measured costs, and a button to load each solution into editable cards. Multiplication was improved from 226 to 192 total test instructions, and primality from 942 to 781. These are efficient measured references, not proven globally fastest solutions. The records report verification of all 33 test queues and every answer-loading path.
